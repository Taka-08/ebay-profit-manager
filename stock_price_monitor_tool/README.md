# 無在庫販売 在庫・価格監視ツール

メルカリ、Amazon、楽天、Yahoo!ショッピング、その他仕入れ元の商品URLを登録し、売り切れ・価格変更・確認が必要な商品を管理するStreamlitツールです。

## 起動方法

1. `stock_price_monitor_tool` フォルダを開きます。
2. `run_monitor_tool.bat` をダブルクリックします。
3. ブラウザで `http://localhost:8504` が開きます。

手動で起動する場合:

```powershell
cd C:\Users\User\OneDrive\ドキュメント\eBay\stock_price_monitor_tool
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py --server.port 8504
```

## 保存先

このツール専用のSQLiteファイルに保存します。

```text
stock_price_monitor_tool\stock_monitor.sqlite3
```

既存のeBay利益計算ツール、出品管理ツール、既存SQLiteデータベースは変更しません。

- 監視商品登録

- 設定

## チェック仕様

最初の安定版として、完全自動スクレイピングではなく、以下の簡易チェックを行います。

- URLにアクセスできるか
- 売り切れ系キーワードが含まれるか
- ページ内から簡易的に価格らしい数値を抽出できるか

取得できない場合は「確認が必要」として履歴に保存します。現在価格を手入力してチェックすることもできます。

## Discord通知

設定画面で Discord Webhook URL を入力・保存すると、以下の判定時にDiscordへ通知します。

- 売り切れ
- 価格上昇
- 価格下落

通知内容:

- 商品名
- 仕入れ元サイト
- URL
- 前回価格
- 現在価格
- 在庫状態
- 検知内容
- 確認日時

Webhook URLが未設定の場合は、Discord通知は送信せず、アプリ画面上の通知のみ表示します。

設定画面の「テスト通知を送信」ボタンで、保存済みWebhook URLへテストメッセージを送信できます。

## 自動監視

設定画面で監視間隔を選び、「監視開始」を押すと自動監視が始まります。

選択できる監視間隔:

- 1分
- 5分
- 10分
- 30分
- 60分

自動監視では、登録済み商品のURLを定期的に確認し、以下を検知します。

- 売り切れ
- 再出品
- 価格上昇
- 価格下落

変化があった場合はチェック履歴へ保存し、Discord Webhook URLが設定されていればDiscordへ通知します。

注意: 現在の自動監視は、Streamlitアプリを起動している間だけ動作します。PCを閉じたりアプリを停止すると監視も停止します。完全な24時間常駐化は、Windowsタスクスケジューラや常駐プロセス化で拡張できます。
